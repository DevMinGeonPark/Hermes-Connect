# Phosphor Icons

Official regular-weight SVGs from [phosphor-icons/core](https://github.com/phosphor-icons/core/tree/2b75f3ad12b420c9504ef05df8d2564a28f8500e), pinned to commit `2b75f3ad12b420c9504ef05df8d2564a28f8500e`.

The SVG files are unmodified upstream assets. `glyphs.js` embeds their original child markup for the preview renderer; paths, proportions, and weight are unchanged. Color inherits `currentColor`. `manifest.json` records aliases and SHA-256 hashes for verification.

Distributed under the included [MIT license](LICENSE). No icon font, CDN, or runtime package download is required.
