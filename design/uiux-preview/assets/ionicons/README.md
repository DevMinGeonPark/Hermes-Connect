# Ionicons

Official outline and filled SVGs from [ionic-team/ionicons](https://github.com/ionic-team/ionicons/tree/d1e2c48641fd5f4910ee42a144dc1c84b1a9a4ee), pinned to commit `d1e2c48641fd5f4910ee42a144dc1c84b1a9a4ee`.

The SVG files are unmodified upstream assets from `src/svg`. `glyphs.js` embeds their original child markup, replacing black paint tokens with `currentColor` for light and dark themes. Paths, view boxes, line caps, and stroke widths are unchanged. `manifest.json` records aliases and SHA-256 hashes of the original files.

Selected navigation tabs use filled variants; inactive tabs use outline variants. Profile identities and document previews also use official filled assets.

Distributed under the included [MIT license](LICENSE). No icon font, CDN, Ionic runtime, or package download is needed at runtime.
